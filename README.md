# Blue Team Operations, Threat Hunting & Incident Response Project
# Overview

As part of my cybersecurity internship at Cyart Tech, I worked on a variety of blue team, threat hunting, incident response, and security operations activities designed to simulate real-world defensive security scenarios. The project focused on detecting threats, analyzing malicious activity, improving visibility across systems, and developing practical experience in security monitoring and incident management using industry-standard open-source technologies.

Working within a controlled lab environment, I gained hands-on experience in threat detection, malware analysis, vulnerability management, security monitoring, and adversary emulation while following modern security operations and incident response methodologies.

# Key Responsibilities
Conducted threat hunting activities using open-source security tools to identify indicators of compromise and suspicious behavior.
Performed malware analysis and forensic investigations to understand malicious activity and attack patterns.
Built and managed a vulnerability management pipeline to identify, prioritize, track, and remediate security weaknesses.
Executed incident response simulations and documented findings through professional incident reports.
Performed network defense and security monitoring activities to improve threat visibility and detection capabilities.
Conducted risk assessments to evaluate potential security threats and business impact.
Applied the Incident Response Lifecycle, including preparation, identification, containment, eradication, recovery, and lessons learned.
Developed Sigma detection rules to improve threat detection and monitoring.
Mapped adversary techniques to the MITRE ATT&CK Framework to better understand attacker behavior and defensive coverage.
Participated in adversary emulation exercises and security validation activities.
Documented technical findings, recommendations, and remediation strategies.
Tools & Technologies

During this project, I utilized a wide range of cybersecurity tools and platforms, including:
Elastic Security & Elastic SIEM, Wazuh, Velociraptor, OpenVAS, DefectDojo, REMnux, MITRE ATT&CK Framework, MITRE Caldera, Suricata, CrowdSec, Metasploit Framework, PowerShell, Google Sheets, Google Docs, Threat Hunting, Security Monitoring & Detection Engineering, Incident Response & Digital Forensics, Malware Analysis, Vulnerability Management, Risk Assessment, Network Defense, Security Operations Center (SOC) Workflows, Sigma Rule Development, MITRE ATT&CK Mapping, Adversary Emulation, Technical Documentation & Reporting

# Project Outcome
This project strengthened my practical understanding of defensive cybersecurity operations and provided hands-on experience with modern security tools, detection methodologies, incident response processes, and threat hunting techniques. It enhanced my ability to investigate security incidents, analyze malicious activity, develop detection content, and communicate technical findings through professional documentation and reporting.
